# Hydrogenuine Community UI

This static UI is the public community shell for the OSS release. It uses the public-safe Hydrogenuine website token language and connects to the local gateway at `http://127.0.0.1:8000/v1` by default.

Routes:

- `#/chat`
- `#/workflows`
- `#/research`
- `#/documents`
- `#/memory`
- `#/approvals`
- `#/receipts`
- `#/settings-models`
- `#/settings-tools`
- `#/settings-data`
- `#/onboarding`
- `#/diagnostics`

Configuration is local browser storage only:

- `hg_api_base`
- `hg_api_key`
