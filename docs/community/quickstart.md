# Quickstart

Run `start.ps1` on Windows or `./start.sh` on Linux/macOS. Open `http://127.0.0.1:4173` and use API key `oss-demo-key`.

The default model provider is deterministic and offline. Configure an OpenAI-compatible local endpoint only when you want live model calls.

Local data is stored in `.hg_community` unless `HG_COMMUNITY_DATA_DIR` is set.
